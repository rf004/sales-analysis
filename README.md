# Advertising Spend & Sales Analysis using Machine Learning

## 📌 Project Overview
This project analyzes the relationship between advertising expenditure and sales performance using data analysis and machine learning techniques. It explores how different advertising channels influence sales and uses Linear Regression to understand the relationship between advertising spend and sales outcomes.

## 🎯 Objectives
- Analyze the impact of advertising expenditure on sales.
- Explore relationships between advertising channels and sales using correlation analysis.
- Visualize data patterns and identify important trends.
- Build a Linear Regression model to understand and predict sales based on advertising spending.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- **Techniques:** Exploratory Data Analysis (EDA), Data Visualization, Correlation Analysis, Linear Regression

## 📊 Project Workflow
1. **Data Loading and Preprocessing:** Load the dataset and prepare it for analysis.
2. **Exploratory Data Analysis:** Examine the data to understand distributions, trends, and relationships.
3. **Data Visualization:** Create plots to compare advertising expenditure with sales.
4. **Correlation Analysis:** Identify relationships between advertising channels and sales performance.
5. **Model Building:** Apply Linear Regression to model the relationship between advertising spending and sales.
6. **Model Evaluation:** Evaluate the model using suitable regression metrics.

## 🔍 Key Insights
- Examines how advertising expenditure relates to sales performance.
- Compares the influence of different advertising channels on sales.
- Uses visualizations and statistical relationships to support data-driven observations.
- Demonstrates how machine learning can be applied to sales analysis and prediction.
